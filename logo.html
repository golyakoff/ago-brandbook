Logo

A wordmark, not a mark

There is no separate logo symbol anywhere in ago-landing or ago-console today — only the "AGO" name, set in the display face, with a small gradient tile carrying its first letter (ago-landing's own .brand .g and ago-console's shell wordmark use the identical idea). That wordmark is the logo for this page's purposes; inventing a new symbol would be adding to the identity, not documenting it.

AAGO

The gradient tile runs --blue → --violet in the landing's own palette (linear-gradient(140deg, var(--blue), var(--violet))) — the same pair shown in the landing swatches.
